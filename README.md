# Paanwin's World Android App

This is an Android WebView app wrapping the current Paanwin's World website. The website is bundled in `app/src/main/assets/index.html` and keeps its Supabase connection.

## Build
Open this folder in Android Studio and choose **Build > Build APK(s)**.

Application ID: `com.paanwins.world`
Version: 1.0 (code 1)
